# Rubrica Pro MERN — DevAppSpace

Corso gratuito di sviluppo web full stack in italiano.

Impara a realizzare un'applicazione completa per la gestione dei contatti utilizzando lo stack MERN: MongoDB, Express, React e Node.js.

## 🎯 Obiettivo del corso

Realizzeremo passo dopo passo una rubrica telefonica, partendo dalla creazione del progetto React fino alla pubblicazione online dell'applicazione completa.

Il corso è organizzato in **36 lezioni suddivise in 6 moduli**, con un approccio pratico e una difficoltà progressiva.
